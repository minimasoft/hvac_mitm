## 4 relay system controller using micropython for a ESP32.
- outputs are configured in the main.py (OUT_PIN_X = Y)
- it contains a small http server in port 11337 with 3 simple endpoints: GET '/' (webpage) POST '/mode' GET '/status' mode allows to post a string for the status set, and get shows the current. 
- the '/' webpage is a very simple html page with a text field and buttons and every 1 second it gets '/status' to show it in the text field and touching the buttons set the state.
- 'bypass' status is all relay outputs in 0
- '30%' / '50%' / '70%' status: relays follow the same dance (1&2 first, 200ms, then 3&4), plus PWM on GPIO 5 at the corresponding duty cycle (30%, 50%, or 70%)
- 'auto-power-save' status: behaves like 30% initially. A timer tracks elapsed time since the last mode change. After 8 hours at 50% or 70%, it auto-drops to 30% (relays stay on, PWM drops to 30%). The status changes to '30%'. The timer resets if the user manually selects a different level.
By default it boots in bypass.

## v2 wifi
On boot and every 5 minutes if connection is lost it should connect to wifi.
- SSID is in file '.ssid' mandatory
- PSK is in file '.psk' optional (open net)
if the .ssid file is missing it just prints a log and do nothing
